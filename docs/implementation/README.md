# Implementation Notes

This folder stores durable engineering records for the PlantUML skill project.
These files explain why the pipeline, release packages, promotion gates, and
verification policy work the way they do.

## What Belongs Here

- Architecture and workflow notes for acquisition, rendering, verification,
  licensing, curation, and skill improvement.
- Validation evidence that should survive regenerated local `data/` outputs.
- Human approval and promotion records for skill candidates.
- Release-readiness notes that describe what was verified before packaging.

Generated manifests, reports, rendered images, downloaded corpora, and
improvement-run state belong under ignored `data/` paths, not here.
