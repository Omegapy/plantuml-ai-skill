# PlantUML AI Skill

An AI skill project for generating, validating, and rendering PlantUML diagrams from natural-language prompts.

## Goal

This project will provide a Python-based workflow that helps agents turn plain-language diagram requests into inspectable PlantUML source, validate that source, and render diagrams for review.

## Python Setup

Create and activate the repo-local virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

The `.venv/` directory is ignored by Git and should not be committed.

## Current Status

This repository is in its initial bootstrap state. Implementation files, dependencies, packaging configuration, tests, and rendering workflows will be added in later development steps.
