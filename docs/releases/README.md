# Release Documentation

This folder documents installable PlantUML Diagram skill packages and release
evidence.

## Current User Guide

`plantuml-diagram-package-installation.md` is the current beginner-facing guide.
It explains how to download one package from GitHub and install it into the
consumer project's `.agents/` folder.

The active package families are:

- macOS/Linux: `plantuml-diagram-<tier>-<version>.tar.gz`
- Windows 11: `plantuml-diagram-<tier>-<version>-windows.zip`
- Checksums: `SHA256SUMS`

## Historical Evidence

`plantuml-diagram-skill-b63b348d98c6.md` records promotion and packaging
evidence for a prior skill artifact. Keep it as release history; do not treat
its legacy installer names as the current package interface.
